# frm/forum web client

frm/forum is an independent web client fork based on the Bluesky Social App and the AT Protocol. It is not operated by, endorsed by, or affiliated with Bluesky Social PBC.

The project is currently scoped to a web release. Native iOS/Android projects and auxiliary services in this checkout are not part of the frm/forum web release unless explicitly enabled later.

## Development

This is a React Native Web / Expo application written in TypeScript. See `docs/build.md` for build instructions.

Protocol references:

- [AT Protocol specifications](https://atproto.com/specs)
- [AT Protocol repository](https://github.com/bluesky-social/atproto)
- [Upstream social-app repository](https://github.com/bluesky-social/social-app)
